# M4 — Codex audit remediation and engineering-proof evidence (2026-11-21)

All findings were reproduced against current source and confirmed valid; none were rejected. Each fix is the
smallest change that restores the invariant; each has a regression test on real PostgreSQL that was shown to fail
against the defective behaviour (H01 mutation run: 6/7 regressions fail when the in-statement time guard is removed).

## Test-harness defects found and fixed during M4 (not product defects)
- Supertest requests are lazy → overlap tests now `start()` requests explicitly.
- `startApp` leaked env overrides across boots/suites → per-boot baseline from `.env` only.
- Prisma auto-loads missing env vars from `.env` on import (documented in the H04 test).
- Restart test read the invocation before its separate FINISH tx committed → waits for the terminal state.
- Scratch-DB FORCE drops ran as owner and could not terminate an exiting app-role backend → test-only superuser.
